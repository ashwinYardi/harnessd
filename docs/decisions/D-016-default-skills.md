# D-016 Default skill pack
Status: accepted 2026-11-20. `harnessd init` installs a default skill pack into `~/.harnessd/skills/`, and `harnessd sync` gives it to every harness. The pack holds Matt Pocock's engineering skills (mattpocock/skills, MIT) for development work and Impeccable (pbakaus/impeccable, Apache 2.0) for anti-slop UI. Each skill is pinned to a version in config, keeps its licence file, and can be turned off per workspace. The Frontend agent uses Impeccable and follows UX and interaction-design principles: loading, empty and error states, keyboard use, visible focus, WCAG AA contrast and stable live updates. QA checks these, so quality does not rest on the skill alone. Why: harnessd builds itself from MET-20 on, and proven skills raise the quality of every PR. Issues: MET-21, MET-18.
