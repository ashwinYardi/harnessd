# D-011 Autopilot; ask only when worth it
Status: accepted; method amended by D-017. Before building, the coordinator grills each issue itself (grill-with-docs method, D-017) and answers from spec, decisions, code and vault. It records each call as a decision note. It asks the human only if the call is: irreversible or costly to undo; needs money, a secret or an account; changes public API, data model or protected paths; or is a product/taste call with no precedent in the spec. Otherwise it decides and proceeds. Escalation = Needs input + one Slack ping; the loop continues on other work.
