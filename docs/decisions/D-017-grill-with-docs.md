# D-017 grill-with-docs replaces grill-me
Status: accepted 2026-11-20. Amends D-011. The coordinator grills each issue with the grill-with-docs method (mattpocock/skills) instead of grill-me. grill-with-docs tests a plan against the project's own docs and decisions, and it writes decision records and a glossary. A call that sets new precedent becomes a draft decision record in a docs PR. New terms go to a glossary in the workspace vault. The D-011 escalation rules do not change. Why: it is more development-oriented, and it keeps `docs/decisions/` current. Issue: MET-22.
