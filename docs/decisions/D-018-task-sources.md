# D-018 Any task tool, or none
Status: accepted 2026-11-20, for v0.2. Replaces D-006 from v0.2 on; until then D-006 holds. Work comes through one task-source interface. Linear is the first adapter. GitHub Issues comes next, through the `gh` CLI (D-002), and other tools plug in the same way. With no task tool, a markdown source keeps one file per task in `<repo>/.harnessd/tasks/`, and the coordinator plans, sizes and works them one by one. A task tool stays the recommended setup. The filing rules in SPEC apply to every source. Why: teams use many task tools, and some use none. Issues: MET-23, MET-26.
