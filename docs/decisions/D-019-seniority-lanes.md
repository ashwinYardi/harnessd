# D-019 Junior and senior lanes
Status: accepted 2026-11-20, for v0.2. Extends D-010. Each agent has a seniority: junior, mid or senior. Config maps each seniority to a harness, model and effort. The coordinator picks the seniority from the task's size, area and risk; a protected path always gets senior. After a QA failure, the next attempt goes up one seniority, within the D-014 limits. Every run logs its model and cost. The first version uses Claude Code alone (Haiku, Sonnet, Opus); other harnesses join when their adapters land. Routing each task to the best harness builds on this. Why: cheap models do most tasks well, which gives more value for the money. Issue: MET-24.
