# D-024 UI transport and read model
Status: accepted 2026-11-20. Extends D-003. The daemon serves the built UI and its data from the same `127.0.0.1:<daemon.port>` server. Vite builds the app into `packages/ui/dist/app` at build time. The daemon serves each built file as an exact GET route, so nothing outside the build is reachable. Read routes return JSON. Live changes reach the UI as server-sent events on one GET stream, not a WebSocket, because the UI only listens and the only writes are the pause routes. The loopback Host check and the JSON content type on POSTs still apply. The board reads Linear through a cache (15 s), because Linear stays the source of truth (D-006) and the API key has a rate limit. "Budget used" is elapsed wall-clock time over the size budget, because that is the budget D-014 enforces. Token use is shown as a count. Why: one process, no new port, no CORS and no vendor SDK (D-002). Issue: MET-18.
